The question

Different tasks.
Different physical evidence.

Understanding a collision requires motion and relative position. Inferring mass from a tower requires geometry, orientation, and support. A single video representation must accommodate these different physical questions.

Our Unified Parser combines object identification, segmentation, geometry, and tracking into one object-centric code. Task-specific abstraction selects and derives the evidence needed for the question.

Visual consistency

Agentic refinement

The VLM writes a Blender program from parsed code, compares its render with the original video, and edits the code directly. It checks intersections, gaps, and temporal consistency without seeing ground truth.

Hamrick pilot, evaluated after code histories were frozen. A frozen tower’s collapse state is not an acceptance criterion.

Task-specific evidence

Adaptive abstraction

A VLM selects and derives code using confidence, length, importance, and relevance. Importance and relevance are VLM-scored; selection iterates within a total video + question + code context budget.

Size N controls the selected evidence set. T controls the number of refinement iterations in the abstraction loop.
